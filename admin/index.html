MongoDB Atlas Connection Setup

Your VASEVINE website is running with a built-in catalog of 80 garments. To enable persistent live orders and store database records, ensure your MongoDB Atlas credentials match:

Steps in MongoDB Atlas (cloud.mongodb.com):

  1. Go to Security > Database Access.
  2. Click Add New Database User.
  3. Set Authentication Method to Password.
  4. Username: QSXgk3OVWCjuv4Hx (or your chosen username).
  5. Password: QSXgk3OVWCjuv4Hx (or your chosen password).
  6. Under Database User Privileges, select Read and write to any database.
  7. Click Add User to save.
  8. Go to Security > Network Access and make sure 0.0.0.0/0 (Allow Anywhere) is added.

If you chose a different username/password, update MONGODB_URI in Vercel > Settings > Environment Variables and redeploy.
